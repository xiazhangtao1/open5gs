终端列表及详情增加“SCTP 对端”，从 AMF 已有 `gnb.peer` 字段显示实际 IP/端口。只显示当前连接：终端为 `connected`、关联状态为 `associated` 且对端有效；空闲、断开、未知或缺失地址均显示“—”，不回退到历史位置。

## 现场相同流量比较

原六个 UE 保持上行 0.5/1/1.5/2/2.5/3 Mbps、下行 1/2/3/4/5/6 Mbps 灌包。升级前后各两轮，每轮每 UE 600 个 ping，间隔 200 ms；升级后同步运行 50 路只读列表、连接详情与精确 SCTP 筛选查询。

| 检查 | 升级前 | 升级后 |
| --- | --- | --- |
| Ping 收到/发出 | 7,200 / 7,200 | 7,200 / 7,200 |
| 各 UE 两轮 P99 RTT 范围 | 28.4–30.5 ms | 28.7–30.7 ms |
| 最大 RTT | 37.5 ms | 41.0 ms |
| UPF 平均 CPU | 0.11157 核 | 0.11136 核 |
| VPP 平均 CPU | 1.02858 核 | 1.02921 核 |
| UPF/VPP 新增 CFS 节流时间 | 0 | 0 |
| UDP 接收日志丢包/总包 | 0 / 393,747 | 0 / 393,751 |

UDP 数量来自接收端末尾日志区间，不严格覆盖完整测量窗口。各 UE 上下行平均速率前后差异最大 0.73%，维持原速率分档；此次短测未观察到可重复的明显业务性能退化，不据此外推线速、所有包长或长期负载结论。

50 路浏览持续 241.08 秒，共 18,022 次请求、0 错误，网页监控接口 P95/P99 为 1.93/4.50 ms；查询始终返回正确的六 UE 与 SCTP 连接关联。UPF 及 AMF/SMF 主要信令采样在浏览前/中分别约 0.4998/0.4978 次每秒，UE/PDU 详情约 0.1 次每秒，基站约每 15 秒一次，没有随浏览人数增加。

监控历史共 31 条，含 6 条承载和 12 条业务规则；采样观测到的监控容器最高内存为 45,633,536 B（43.52 MiB / 512 MiB），无保护暂停、拒绝批次或回收。结束后 monitor/decoder 的 cgroup 内存分配失败与 OOM 计数均为零。所有 xcn Pod 就绪且零重启，六 UE 已连接、上下行速率非零，原灌包容器持续运行。

接口延迟仅表示监控请求，不作为用户面时延；用户面 RTT 使用上表独立 UE ping 测量。完整页面交互使用隔离账号，现场验证使用已授权的短期只读 API 令牌。
