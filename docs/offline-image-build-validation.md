- 从 Git 暂存区导出的干净副本执行两套完整构建，不包含本机未跟踪的镜像包、被忽略的子项目源码、node_modules 或 .next。
- 联网完整流程退出 0，约 543 秒（使用部分已有构建层缓存）；三镜像均构建完成，自动 push 失败后继续并正常汇总。
- 断网冷构建退出 0，约 2555 秒。独立 Docker `--internal` 网络中仅有临时 Jammy APT 服务器，保留 Ubuntu 签名校验，预置 215 个 deb 和 14 个索引。公网连接实测返回 `Network is unreachable`，三镜像均从源码/归档完成构建；npm 使用 offline、pip 使用 no-index/hash 校验、Meson 禁止下载。
- 构建使用空闲 CPU 36、37，两个编译作业，单次构建 1.5 CPU / 4 GiB，主机网络为正常构建默认值；仅断网验收显式切换内部 Docker 网络。

- 仍为 5 个 Pod、17 个常规容器、5 类镜像；没有增加 Pod/容器。
